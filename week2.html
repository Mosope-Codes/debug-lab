Lab tasks (open DevTools first, then work through them)
  1. Users says "0 users". What does the Network panel say about that request?
  2. Orders takes a long time. Is it the network or the server? Use the Timing tab.
  3. Monthly report just says "unavailable". Find the server's actual error message.
  4. Profile shows "undefined". Compare what the server sent with what the page reads.
  5. Live stats fails. What do the Console and Network panels each tell you? Which side has to change?
  6. Config version never changes when you refresh. Why? Check the Size column, then use Disable cache.
  7. Payments gateway fails once. Use Preserve log, then Copy as fetch, and replay the call from the Console.
  8. Set throttling to Slow 4G and reload. Then block the orders request and see how the page copes.
  9. Application panel: click "Simulate a bad deploy", reload, and find what broke. Also find the session cookie.
